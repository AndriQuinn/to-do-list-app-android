# To - Do List App 📱 [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
A very simple Android app to manage your daily tasks.

<img src="https://github.com/AndriQuinn/to-do-list-app-android/blob/main/assets/To%20-%20Do%20List%20Banner.png?raw=true" width="100%" alt="Banner">

## Features 🚀
- Simple and Clean UI
- Add and Delete To - Do's
- Mark To - Do's as Done
- Room Integrated

## Installation ⬇️

Information:

- Minimum Sdk = 24
- Version = 1.0.1
- App Size = 8MB

1. Release:
   - Click the release
   - Download the apk
   - Done! 🥳

2. Clone the repository:
      ```bash
        git clone https://github.com/AndriQuinn/to-do-list-app-android.git
      ```
   - Open in Android Studio
   - Sync Gradle
   - Run on device or emulator
   - Done! 🥳
